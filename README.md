# 手动天气

在网络不可用时离线推算天气温度。

## 功能

- 输入当天最高温、最低温。
- 可选择省略温度小数，将显示值四舍五入为整数。
- 设置最低温出现时间，默认 05:00。
- 设置最高温出现时间，默认 14:00。
- 使用余弦曲线估算全天和未来 24 小时的温度变化。
- 鼠标悬停时平滑定位到对应时刻，提示框淡入淡出并显示温度。
- 温度设置变化时，预览曲线会平滑变形而不是瞬间跳变。
- 同步到 ClassIsland 自带的天气组件、天气提醒和天气页。
- 可选择晴、多云、雨、雪等天气状态，用于显示对应图标。
- 配置保存在插件的独立配置目录中。

## 温度估算方法

插件把一天分为升温和降温两段：

- 从最低温时刻到最高温时刻使用半周期余弦平滑过渡。
- 从最高温时刻到次日最低温时刻使用另一半周期余弦平滑过渡。

这不会产生精确气象预报，但能得到自然、连续的全天温度曲线。

## 使用

1. 安装插件后，打开应用设置。
2. 进入“手动天气”。
3. 输入最低温、最高温，并按需要调整最低/最高温时刻。
4. 返回主界面，使用现有的天气组件查看结果。

## 构建

1. 在仓库根目录运行 `dotnet build ManualWeatherPlugin.csproj -c Debug`。
2. 构建完成后，插件包位于 `cipx/ManualWeatherPlugin.cipx`。
